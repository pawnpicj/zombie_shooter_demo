# DEAD ZONE — Three.js Zombie Shooter

เกมเอาชีวิตรอดมุมมองเฉียง 3 มิติสำหรับคอมพิวเตอร์ ใช้ Three.js 0.180.0
ทุกโมเดลสร้างด้วย geometry ในโค้ด ไม่ต้องโหลดภาพ โมเดล หรือเสียงจากภายนอก

## เริ่มเล่น

ต้องมี Node.js และ npm

```powershell
cd D:\MyDev\CodexProject\zombie-shooter
npm install
npm start
```

เปิด http://127.0.0.1:5173 แล้วกดเข้าสู่เขตกักกัน
หลังติดตั้ง dependency แล้วสามารถเล่นโดยไม่ต่ออินเทอร์เน็ตได้
เซิร์ฟเวอร์รับการเชื่อมต่อจากเครื่องนี้เท่านั้น

## การควบคุม

- WASD / ปุ่มลูกศร: เคลื่อนที่
- เมาส์: เล็ง / คลิกซ้ายค้าง: ยิง
- R: รีโหลดจากกระสุนสำรอง
- Space: พุ่งหลบ คูลดาวน์ 2.5 วินาที
- Esc: พัก / เล่นต่อ (เกมพักอัตโนมัติเมื่อสลับหน้าต่าง)
- ปุ่มเสียง: เปิด / ปิดเสียงสังเคราะห์

## ระบบเกม

- เวฟซอมบี้เพิ่มจำนวน ความเร็ว และพลังชีวิต
- ตัววิ่งเร็วเริ่มเวฟ 2 ตัวใหญ่เริ่มเวฟ 3
- อัปเกรดปืนด้วยเงินและวัสดุในร้าน [B]
- ฟื้นพลัง 12 HP เมื่อเข้าเวฟใหม่ และชุดพยาบาลรักษาได้ 30 HP
- ที่กำบังขวางทั้งตัวละครและกระสุน
- คะแนนสูงสุดบันทึกใน localStorage ของเบราว์เซอร์
- รองรับการเล่นซ้ำ เสียง การหยุดเกม และหน้าสรุปคะแนน
- ใช้คีย์บอร์ดและเมาส์ ยังไม่มีปุ่มสัมผัสสำหรับมือถือ

## Browser integration checks (optional)

With the localhost server running, install Puppeteer as a temporary test tool:

```powershell
npm install --no-save puppeteer
node tests/browser-smoke.mjs
node tests/browser-combat.mjs
```

Alternatively, set PUPPETEER_MODULE to an existing Puppeteer installation and CHROME_PATH to a Chrome executable.
The tests launch a headless browser and validate actual controls, combat, wave completion and restart.
Screenshots are written to artifacts/.

## แอป Windows

เปิดไฟล์ `dist/DeadZone-win32-x64/DeadZone.exe` หลังสร้างแอปแล้ว
ต้องเก็บไฟล์ทั้งหมดในโฟลเดอร์เดียวกัน ไม่ย้ายเฉพาะไฟล์ exe
เวอร์ชัน Windows เปิดเกมจากไฟล์ในแอปโดยตรง ไม่ต้องเปิดเบราว์เซอร์หรือรันเซิร์ฟเวอร์

- **F11 / Alt+Enter**: สลับเต็มหน้าจอและกลับโหมดก่อนหน้า
- **F10**: สลับหน้าต่างมีขอบและหน้าต่างไร้ขอบ
- เมนูด้านบน: เลือกโหมดและขนาดหน้าต่าง
- ลากแถบชื่อเพื่อย้ายหน้าต่าง หรือในโหมดไร้ขอบลากบริเวณว่างของส่วนหัว
- แถบชื่อมีปุ่มย่อ ขยาย และปิดหน้าต่าง
- บันทึกโหมดและขนาดหน้าต่างสำหรับการเปิดครั้งถัดไป
- การเปลี่ยนโหมดไม่โหลดเกมใหม่ จึงไม่ล้างคะแนนหรือเวฟปัจจุบัน
- หน้าต่างไร้ขอบซ่อนแถบชื่อและกรอบตกแต่ง โดยคงขนาดหน้าต่างไว้

รันจาก source หรือสร้างแอป Windows:
```powershell
npm install
npm run desktop
npm run build:windows
```

ทดสอบหน้าต่าง Windows:
```powershell
npm run test:desktop
```

## เนื้อเรื่อง Virus X — เวอร์ชัน 1.1

เลือกเนื้อเรื่องหรือโหมดเอาชีวิตรอดจากหน้าเริ่มเกม
ผู้เล่นเป็น John Valentine เจ้าหน้าที่หน่วยรบพิเศษที่เข้าตรวจสอบ REGEN-X Lab

1. กำจัดผู้ติดเชื้อ แล้วกู้บันทึกจาก SECURITY ทางซ้ายบน
2. กำจัดผู้ติดเชื้อ แล้วเก็บสูตร REGEN-X และตัวอย่าง Virus X ที่ RESEARCH ทางขวาบน
3. กำจัดฝูงสุดท้าย แล้วถอนกำลังที่ EXTRACTION ด้านล่าง

เมื่อเคลียร์พื้นที่แล้ว เข้าใกล้วงแหวนสีเขียวและกด **E**
หน้าบันทึกจะพักเกมไว้จนกดไปภารกิจถัดไป
มีฉากจบหลังถอนกำลัง และเริ่มเรื่องใหม่ได้
รายละเอียดเนื้อเรื่องอยู่ใน STORY.md

ทดสอบการเล่นครบทั้งเรื่องบน Browser:
```powershell
npm run test:campaign
```
ใช้การตั้งค่า Puppeteer ตามหัวข้อ Browser integration checks ข้างต้น

แผงวิทยุ ภารกิจ และกระสุนจะย่ออัตโนมัติหลังแสดงครบ 10 วินาที เลื่อนเมาส์ไปที่แถบเพื่ออ่านรายละเอียด โดยยังยิงผ่านบริเวณแผงได้ ข้อความวิทยุหรือภารกิจใหม่จะแสดงเต็มอีก 10 วินาที และเมื่อเล่นต่อจากการพักเกมทั้งสามแผงจะแสดงเต็มอีกครั้ง


## Level และ Status — เวอร์ชัน 1.2
- กำจัดซอมบี้รับ EXP: ปกติ 20, ตัววิ่ง 30, ตัวใหญ่ 60
- เริ่ม Level 1 ที่ 100 HP; ทุก Level เพิ่มพลังชีวิตสูงสุด 20 HP และฟื้นเต็มทันที
- ทุก Level ได้ 3 Points ใช้ครั้งละ 1 แต้ม เก็บแต้มไว้เลือกภายหลังได้
- กด Tab หรือปุ่ม STATUS เพื่อเลือกอัปเกรด เกมพักระหว่างเลือก
- Power Attack: พลังโจมตี +10% ต่อแต้ม
- Attack Speed: อัตรายิง +8% ต่อแต้ม
- Movement Speed: ความเร็วเดิน +5% ต่อแต้ม
- Gun Reload: ความเร็วรีโหลด +10% ต่อแต้ม (เวลารอ = 1.35 / (1 + 0.10 × rank))
- Critical Damage: ความเสียหายคริติคอลจาก 150% เพิ่ม 20 จุดเปอร์เซ็นต์ต่อแต้ม โอกาสคริติคอล 10%
- ค่า Level และแต้มอยู่ตลอดรอบที่เล่น รวมทุกบทของเนื้อเรื่อง การพักและเปลี่ยนโหมดหน้าต่างคงค่าไว้ เริ่มเกมใหม่จะรีเซ็ต
- EXP ที่ต้องใช้เริ่ม 100 และเพิ่ม 50 ต่อ Level

ทดสอบระบบ Level ใน Browser ด้วย `npm run test:level` โดยใช้การตั้งค่า Puppeteer ข้างต้น


## เงิน กล่อง และอาวุธ — เวอร์ชัน 1.3
- กำจัดซอมบี้รับเงิน: ปกติ $25, ตัววิ่ง $35, ตัวใหญ่ $75 เงินแยกจาก Points
- B หรือปุ่มร้าน: เปิดร้าน เกมพักระหว่างซื้อและอัปเกรด
- อัปเกรดอาวุธที่มีแล้วใช้ทั้งเงินและวัสดุ เพิ่มพลังโจมตี 15% ต่อ Level ค่าเริ่มต้น $180 + 6 วัสดุ และเพิ่ม $120 + 4 วัสดุต่อขั้น
- อาวุธใหม่เก็บจากจุดใน Lab เท่านั้น ร้านไม่ขายอาวุธและกล่องสุ่มไม่มีอาวุธ เริ่มด้วย M4; SMG ทางตะวันตก (-18,0), Shotgun ทางตะวันออก (18,0), DMR ทางเหนือ (0,-18)
- F เปลี่ยนอาวุธที่เก็บมาแล้ว แต่ละกระบอกอัปเกรดแยกกัน ปืนใช้กระสุนสำรองร่วมกัน ไม่เติมฟรีเมื่อเปลี่ยนปืน
- E เปิดกล่องใกล้ตัว: กล่องวัสดุให้วัสดุ 6–10; กล่องสุ่มให้หนึ่งอย่างจากวัสดุ 5, กระสุน 90, ยาวิ่ง 1 หรือโล่พลังงาน 1
- กล่องวัสดุและกล่องสุ่มประจำ Lab เติมเมื่อเข้าบท/เวฟใหม่ ซอมบี้มีโอกาสทิ้งกล่องสุ่มเพิ่มเติม
- กระสุนสำรองเริ่ม 240 ใช้จริงเมื่อรีโหลด กล่องกระสุนที่ (0,14) และ (0,-10) ให้ 90 และเติมใหม่หลัง 25 วินาที
- V ใช้ยาวิ่ง: เดินเร็วขึ้น 35% นาน 12 วินาที หยุดนับเมื่อพักเกม ใช้เพิ่มระหว่างฤทธิ์ยายังทำงานไม่ได้
- C ใช้โล่พลังงาน: เพิ่มโล่ 60 สูงสุด 120 โล่รับความเสียหายก่อน HP
- ระเบิดได้จากซื้อเท่านั้น ไม่ออกจากกล่องหรือศัตรู: ขวดเพลิง $120, ทำลายล้าง $180, แตกกระจาย $240
- Q เปลี่ยนชนิดระเบิด; G ขว้างไปยังตำแหน่งเล็งได้ไกลสุด 14 เมตร
- ขวดเพลิง: ไฟรัศมี 3.2 เมตรนาน 6 วินาที ความเสียหาย 40 ต่อวินาที
- ทำลายล้าง: ความเสียหาย 220 รัศมี 5 เมตร
- แตกกระจาย: ระเบิดหลัก 120 รัศมี 3 เมตร และลูกย่อย 6 ลูก ลูกละ 100 รัศมี 2 เมตร
- เงิน วัสดุ อาวุธ และไอเทมอยู่ตลอดรอบที่เล่นรวมทุกบท การพักและเปลี่ยนหน้าต่างคงค่าไว้ เริ่มเกมใหม่จะรีเซ็ต

ทดสอบด้วย `npm test` และ `npm run test:supplies` (ตั้งค่า Puppeteer เช่นเดียวกับหัวข้อ Browser integration checks)

## Phase 2 — Core Player Systems

กด E จะแสดงคำสั่งสำหรับจุดโต้ตอบเดียวที่ใช้ได้ในระยะ หากภารกิจและของอยู่ในระยะพร้อมกัน จะให้ภารกิจมาก่อน การพักหรือเสีย focus ล้างปุ่มเดินและยิงที่ค้างไว้; กลับมา focus ต้องกดเล่นต่อเอง

ทดสอบ core ด้วย `npm run test:core` โดยตั้งค่า Puppeteer/Chrome ตาม Browser integration checks รายละเอียดผลและขอบเขตอยู่ใน `docs/PHASE2_CORE_SYSTEMS.md`
